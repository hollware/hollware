# hollware

The command line of [Hollware](https://github.com/hollware/hollware), an open-source headless
CMS for the agent era, native to Cloudflare Workers.

> **Status: pre-alpha, not usable yet.** The binary answers `--help` and `--version`; every
> command prints "not implemented yet" and exits with code 1.

## What it will be

The `hollware` command, with these planned commands:

| Command   | Purpose                               |
| --------- | ------------------------------------- |
| `init`    | Set up Hollware in a project          |
| `migrate` | Apply D1 migrations                   |
| `token`   | Create, list and revoke access tokens |
| `import`  | Import Markdown files over MCP        |
| `export`  | Export entries as Markdown files      |
