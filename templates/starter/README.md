# Hollware starter

The project template behind `npm create hollware`. `create-hollware` will copy this directory
into new projects starting with v0.4. Until then it is a placeholder that keeps the stack
honest: it builds, type-checks and tests with the same tools a Hollware project will use.

Today the Worker answers every request with `501` and the text `Hollware is not implemented yet.`.

## What is inside

| Path                        | What it is                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------ |
| `wrangler.jsonc`            | The Worker `my-hollware` and its D1 binding `DB`                                           |
| `src/worker.ts`             | The Worker                                                                                 |
| `vite.config.ts`            | Vite with `@cloudflare/vite-plugin`                                                        |
| `vitest.config.ts`, `test/` | Tests that run inside workerd through `@cloudflare/vitest-plugin`                          |
| `worker-configuration.d.ts` | Generated by `wrangler types`. Commit it, and refresh it whenever `wrangler.jsonc` changes |

The D1 binding reads its migrations from `node_modules/@hollware/server/migrations`, the
directory the server package ships. Its `database_id` is a placeholder that works for local
development; put the id of your own database there before deploying.

## Commands

| Command            | What it does                                         |
| ------------------ | ---------------------------------------------------- |
| `pnpm dev`         | Serve the Worker locally with Vite                   |
| `pnpm build`       | Build the Worker into `dist/`                        |
| `pnpm test`        | Run the tests in workerd                             |
| `pnpm types`       | Regenerate `worker-configuration.d.ts`               |
| `pnpm types:check` | Fail when `worker-configuration.d.ts` is out of date |
