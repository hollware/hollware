# @hollware/core

The contracts, schemas and Markdown pipeline of [Hollware](https://github.com/hollware/hollware),
an open-source headless CMS for the agent era, native to Cloudflare Workers.

> **Status: pre-alpha, not usable yet.** This release only reserves the package name and
> exports its own name. There is no API to depend on, and everything will change.

## What it will be

The runtime-agnostic heart of Hollware: the definitions of config, collections and
components, the contracts that validate every write, and the Markdown pipeline. It has no
Cloudflare dependencies, so it runs anywhere.
