Hollware 1.0: from this release on, a minor or patch version keeps working everything an agent, a site, a script or a project built against an earlier 1.x (ADR-036): the MCP tools with their scopes and schemas, the read API at `/v1`, the RPC entrypoint `Hollware`, the events of webhooks, the CLI's commands and flags, every package's exports, and the migrations already shipped. Every package of Hollware takes this version. See "Versions and stability" in the docs.
