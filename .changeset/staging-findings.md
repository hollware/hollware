The embedding model is the Worker variable `HOLLWARE_EMBEDDING_MODEL` (`@cf/baai/bge-m3` when not set); its Vectorize index must have been made for its dimensions. `HollwareEnv` takes the `VectorizeIndex` type that `wrangler types` writes for a Vectorize binding. The read API says how long a read took on the server, after the token check, in `Server-Timing: read;dur=<ms>`.
