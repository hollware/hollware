A new package: Hollware for any React app. `createHollware` reads published entries, listings and translations from a loader, a Server Component or a server function, over a service binding or HTTP; `previewRedirect` and `previewHeaders` serve a preview link of a draft; and `<HollwareContent>` renders an entry's Comark document with your own React components, on the server and in the browser.
