The editor saves only when the person asks: the Save button beside Publish, or ⌘S (Ctrl+S). Typing no longer writes a revision every 8 seconds, nor when the tab is hidden, so the history keeps only the versions someone chose to save. This browser still keeps what was typed until it is saved, as before. Leaving an entry with changes asks first: save and leave, leave without saving (which drops the kept copy), or keep editing; the browser asks too before closing the tab. Publishing, scheduling and opening a preview on the site still save first, as they did.
