Tokens makes a lasting token for an agent member as well as for you: choose the agent under For, or follow the key of the agent in Agents. Its scopes are those an agent may hold, a read token is not offered, and a token of any kind may end on a date (Expires on) as well as after a number of days or never. The table marks the tokens of agents.
