# @hollware/client

The typed client of [Hollware](https://github.com/hollware/hollware), an open-source headless
CMS for the agent era, native to Cloudflare Workers.

> **Status: pre-alpha, not usable yet.** This release only reserves the package name and
> exports its own name. There is no API to depend on, and everything will change.

## What it will be

One typed interface to read published content, over either a Cloudflare service binding or
HTTP. A site picks the transport; the calls stay the same.
